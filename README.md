# 🚀 RAJA BISWAS | Full Stack Web Developer Portfolio

## 📋 Project Overview

A cutting-edge, interactive portfolio website featuring a 300-frame 3D character animation, smooth scrolling experience, and fully functional contact form with EmailJS integration. This modern portfolio showcases professional skills, projects, and services with an immersive user experience.

---

## 🛠️ Technology Stack

| Category | Technologies Used |
|----------|-------------------|
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |
| **Animation Engine** | GSAP (GreenSock Animation Platform), ScrollTrigger |
| **Scroll System** | Locomotive Scroll |
| **3D/Canvas** | HTML5 Canvas API (300-frame character sequence) |
| **Email Service** | EmailJS (Email delivery without backend) |
| **Icons** | Font Awesome 6 |
| **Responsive Design** | Mobile-first approach with CSS media queries |
| **Performance** | Image lazy loading, retry mechanisms |
